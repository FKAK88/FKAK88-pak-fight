# Pak Fight Karo — Political Arena

A lighthearted parody fighting game featuring cartoon caricatures of Pakistani political figures. Purely fictional and for entertainment only.

## How to play

Open `index.html` in any modern browser — no install needed.

- **P1:** A/D move, W jump, S block, F punch, G kick, H special
- **P2:** ←/→ move, ↑ jump, ↓ block, K punch, L kick, ; special
- Modes: 1P vs CPU or 2 Players, best of 3 rounds
